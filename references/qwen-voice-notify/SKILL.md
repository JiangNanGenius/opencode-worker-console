# 千问语音提醒（云端优先，本机回退）

本机已安装离线 Qwen3-TTS 模型和独立环境，同时复用 OpenCode 中已有的火山方舟
Agent Plan 语音能力。默认优先云端 `seed-tts-2.0`（默认音色 Vivi 2.0），云端在
播放开始前不可用时自动改用本机离线音色（默认 Vivian）。无需启动常驻服务，不用
macOS 的 `say`。共用语速默认 `1.1×`。

## 何时使用

- 用户主动要求播报时，按用户指定内容播放；不要擅自朗读整段任务结果。
- 自动提醒仅限必须本人完成的实体按键、插拔设备或平台强制本人完成且工具无法代办的操作。先尝试已授权的工具代办，不把普通点击、登录或授权请求一概当作必须本人操作。
- 自动提醒用一句简短中文说清需要做什么。同一未变化的阻碍只播报一次。日常进度、任务完成和一般确认保持安静。
- 播报不替代聊天中的必要说明，不朗读凭据或无关隐私。

## 调用

从任意项目调用，文本经标准输入传递，避免把文字当作 shell 代码执行：

```bash
~/.local/share/qwen-voice-notify/venv/bin/python \
  ~/.codex/skills/qwen-voice-notify/scripts/notify.py speak <<'TEXT'
请按一下设备上的确认按钮，我在等你完成这一步。
TEXT
```

常用参数：

- `--backend auto|cloud|local`：默认 `auto`，优先云端并在播放开始前失败时回退本机；
  `cloud` 仅云端且不回退；`local` 仅本机、不访问网络。
- `--rate 0.5..2.0`：语速，默认 `1.1`；云端使用原生 `speech_rate`，本机使用
  保持音高的 ffmpeg `atempo`，不会二次变速。
- `--voice Serena`：临时指定本机回退音色；默认读取保存值，未保存时为 Vivian。
- `--cloud-voice <id>`：临时指定云端音色；默认 Vivi 2.0。
- `--language English`：临时指定语言；默认 Chinese，支持中英混合。
- `--timeout 180`：云端和播放各阶段的单步超时秒数。

其他子命令：

- `status`：检查模型完整性、扬声器、云端密钥是否已配置、当前设置、活动状态和最近一次
  性能数据；只做元数据检查，不合成、不播放、不访问云端。
- `stop`：停止本 Skill 当前的合成或播放并释放资源。

输入最长 200 字符，较长的主动朗读请求拆成自然段依次调用。并发时第二次调用返回
`busy`，不后台排队重复通知。

## 设置

控制台“模型与路由”的“语音提醒”卡片和本 Skill 共用
`~/.config/qwen-voice-notify/settings.json`：

```json
{
  "schema": 2,
  "voice": "vivian",
  "cloud_voice": "zh_female_vv_uranus_bigtts",
  "backend": "auto",
  "rate": 1.1
}
```

- 缺省值：本机回退 Vivian、云端 Vivi 2.0、`auto`、`1.1`。缺少 `rate` 时始终按
  `1.1` 处理。
- 控制台保存是原子合并；旧版只保存 `voice` 时不会清掉 `cloud_voice`、`backend`
  或 `rate`。
- 显式 CLI 参数覆盖保存值；单次播报的 `--voice`、`--cloud-voice`、`--backend`、
  `--rate` 只影响本次。
- 已保存值无效时使用安全默认值（本机 Vivian、云端 Vivi 2.0、`auto`、`1.1`），
  不会使用越界语速或未知后端。

## 云端、回退与音频

- 云端只使用 Agent Plan 专用端点
  `https://openspeech.bytedance.com/api/v3/plan/tts/unidirectional`，资源
  `seed-tts-2.0`；不得改用通用按量端点。
- 密钥在运行时从 OpenCode 的 `volcengine-agent-plan` provider 读取，仅用于请求头；
  不写日志、不放进 argv 或环境变量、不返回给接口。
- 云端返回 NDJSON：`code=0` 的 `data` 是 base64 音频，`code=20000000` 是成功终止；
  其他错误码、空音频、缺失终止、损坏 base64/JSON 和超大返回都判失败。网络使用约
  5 秒连接/读超时和 15 秒硬总时限，避免拖慢本机回退。
- `auto` 在播放开始前遇到网络、超时、服务、密钥、鉴权/额度、协议或解码失败时回退
  本机，并在 `last-run.json` 记录实际后端、语速、回退原因和脱敏云端状态。缺失密钥、
  鉴权或额度问题会给出可操作原因，不把整个功能说成离线。本机模型缺失不会阻止
  `auto`/`cloud` 尝试云端；只有实际回退或 `local` 模式才需要本机模型和音色目录。
- 播放一旦开始或已取消，绝不再回退或重读文本。`cloud` 模式失败只报错，不回退。
- 本机合成进程先退出，再按需做 `ffmpeg atempo`，最后才播放；`1.0×` 原样直通，
  不改变采样率或音高。云端音频只解码，不再次变速。
- 临时音频、子进程和活动状态在结束、失败或取消后清理；不下载模型、不常驻推理服务。

## 运行约定

- 模型与独立环境在 `~/.local/share/qwen-voice-notify`，不修改当前项目。
- 指定 CoreAudio 的 Mac mini 内置扬声器，不修改默认输出或音量；设备不可用则报错。
- 不自动播放；只有显式调用或“必须本人完成”的阻碍才播报。普通进度、完成和确认保持安静。
- `status` 的播放成功只证明音频输出调用完成，不能证明用户实际听到或认可音色。
- 失败时说明脱敏后的原因，不循环重试，不静默改用系统 TTS。
- Skill 安装到用户级发现目录；新会话应能发现。旧会话若尚未刷新，可直接使用以上绝对路径。
