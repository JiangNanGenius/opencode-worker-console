# 信息牌视觉规范

Operate 模式。320×480 竖屏。无装饰渐变、无滑动动画、无跑马灯。

- 背景 #171B1E，面板 #22282C，主文字 #F2F0E9，次文字 #AEB8BC。
- 运行/正常 #73D5AC，等待/过期 #F3BE69，错误 #EC8A83，分隔线 #384247。
- 顶部 [0,88)，主体 [88,448)，页脚 [448,480)。左右内边距 16px。
- 中文 efontCN_16；数字 Font4/Font7。标题最多两行，按实际像素宽度截断。
- 任务页每页两项；供应商每页两项。无虚构进度。额度进度条只表达真实剩余比例。
- 顶部固定 HH:MM、秒、日期星期与任务数量；页脚显示页面名称、连接状态、暂停和轮播进度。
- 用 320×40 RGB565 条带缓冲计算像素校验，只有变化条带发送给屏幕，不清空显示面板。
- PC SDL 和 ESP32 共用 board_ui.hpp；预览明确标记实时快照或测试场景。

## Components

### 快捷设置与设备信息

- 沿用现有 320×480 分区、配色与字体。菜单只替换主体和页脚，顶部时间常驻；五行依次为设备信息、屏幕亮度、自动轮播、时间时区、返回信息牌。
- 选中行使用面板底色和绿色标题，右侧以次文字显示当前值；行距 51px，选中底板为 296×43px。不增加装饰、动画或新的视觉 token。
- 长按满 1 秒打开菜单；短按循环选择五行，长按确认。设备信息显示 IP、Wi-Fi 名称与连接状态、固件版本、当前显示的 UTC 偏移；短按或长按返回设置。
- 亮度按 25% / 50% / 75% / 100% 循环；轮播在开启与暂停之间切换；两项选择即时生效并保存，重启后恢复。
- 进入菜单暂时停止轮播；“返回信息牌”或 60 秒无操作退出，恢复用户选择的轮播状态并重新计时。页脚显示按键提示，菜单底部注明自动返回时间。

### 时间显示

- 时间时区提供“跟随 Mac”和“北京时间”，选择即时生效并保存。跟随模式使用 Mac 快照的 UTC 秒偏移，固定模式使用 UTC+8；小时、日期与星期始终采用同一偏移。
- 保留最近收到的有效 Mac UTC 偏移，未收到时以 UTC+8 为默认；设备信息显示实际采用的偏移。未取得有效时间时显示“--:--”及“等待校时”，不编造时间。

### 磁盘概览

- 系统页显示三行磁盘，文字位置为 y=258 / 286 / 314，左侧名称按 125px 宽度截断，右侧显示“可用 / 总量 GiB”。每行下方（y+20）用现有进度条表达已用比例，达到 90% 使用等待色；缺少磁盘时显示“磁盘未挂载”。
- 数据包括内置 Mac SSD，以及自动发现的已挂载外置物理卷，最多三项；排除恢复卷及磁盘映像，不把缺失卷或历史容量补成当前数据。

### OpenCode 模型行

- 每页仍为两项任务；OpenCode 卡片高度为 143px，项目名下方（y+105）以现有绿色显示模型，按 288px 实际宽度截断。Codex 卡片保持 132px，不添加模型行。
- 模型名称只来自任务记录的 actual_models 实测值，保留实际名称并可并列显示多模型；无有效值时明确显示“模型未知”，不依据任务档位、配置或供应商推断。
