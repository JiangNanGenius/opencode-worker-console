Automatic routing

Stages are tried from left to right. Models in one stage share work by weight. Quota adaptation is opt-in per two-provider stage.

Level 1 gradually adds the later fallback below the main runway threshold. Level 2 temporarily routes automatic Normal work through the Fast source pool below its threshold; Deep never changes. Set Level 2 to 0 to disable it.

Each Codex conversation gets its own independent worker slots. There is no shared global or provider-wide cap across conversations.

Optional. Reserves a share of the Kimi plan quota for deep tasks; 0 means no reservation. Plan-backed Kimi is already preferred whenever subscription allowance exists.

At or below the threshold, normal work leaves Kimi and only this many native K3 deep jobs may run globally. Confirmed quota and 429 stops continue in the same OpenCode session on the next route.

Only breaks a Fast/Normal tie. Runway compares remaining quota with time until reset; 100% means on pace. Required Normal/Deep work is never downgraded.

Notifications & long-task continuation

The Worker Desk four-square icon uses the GitHub repository URL and is cached by Bark after download. Clear it to use Bark's default icon.

Each event is sent independently to every listed Bark client. One failed client does not block the others.

Worker execution permissions

Enabled by default; workers can use tools to complete tasks without prompting each time. Task scope is constrained by instructions and checked afterwards. When disabled, file scopes and a command allowlist apply. Affects only this Worker service.

Automatic low-disk cleanup

Only this tool's expired run artifacts and linked archived sessions are touched. Worktrees, patches, reports and recent tasks are retained.

Provider budget signals

Use live telemetry when available. Providers without usage APIs can use a manual reset window or monetary low-balance threshold. These signals only break a Fast/Normal tie.

Service credential references

DeepSeek and Kimi reuse OpenCode authentication. Ark quota and Bark notifications use private references. Worker Desk stores only an environment-variable name or owner-only file reference; secret values are never returned.
